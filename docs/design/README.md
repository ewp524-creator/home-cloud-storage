## Diagram Coverage

Each language version contains:

1. Use Case diagram
2. Activity diagram
3. Sequence diagrams
4. Communication diagram
5. Interaction Overview diagram
6. Timing diagram
7. State Machine diagrams
8. Class diagrams
9. Object diagram
10. Package diagram
11. Component diagram
12. Composite Structure diagram
13. Deployment diagram
14. Profile diagram
15. Entity Relationship diagram as supplementary data design

The diagrams use Mermaid syntax so they can be reviewed directly in GitHub,
GitLab, Codex, VS Code, and other Markdown renderers with Mermaid support.
