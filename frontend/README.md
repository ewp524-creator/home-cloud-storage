# File Home Frontend

基于 Vue 3 与 Vite 的个人文件存储与共享系统前端原型，当前使用模拟数据展示完整界面与交互。

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

## 模块结构

```text
src/
├─ components/
│  ├─ auth/       登录与注册
│  ├─ common/     全局提示
│  ├─ files/      文件卡片、列表、详情、预览、上传与右键菜单
│  ├─ layout/     侧边栏与顶部导航
│  ├─ overlays/   弹窗、确认框与分享设置
│  └─ views/      文件库、分享中心与回收站
├─ composables/   文件业务状态与依赖注入边界
├─ data/          演示数据
├─ styles/        设计变量与全局样式
└─ utils/         文件格式识别与格式化工具
```

## 已实现的交互

- 文件/文件夹网格与列表视图、排序、类型筛选和全局搜索。
- 文件夹树导航、双击进入文件夹、单击选择、右键查看详细信息。
- 文件夹与文件可拖拽到其他文件夹，目录层级同步更新。
- 右键复制后可粘贴到其他文件夹，支持 `Ctrl+C` / `Ctrl+V`。
- 文件夹下载生成保留完整层级的 ZIP，上传文件会写入真实内容。
- 分享文件夹时，全部子文件夹和文件会递归进入分享范围。
- 面包屑返回、多选、批量下载/分享/删除。
- 浮动命令终端，支持自由拖动、右下角缩放和字号调节。
- 终端支持 `ls`、`cd`、`open`、`cp`、`mv`、`delfile`、`deldir`、`find`、`download`、`upload`、`mkdir`、`home` 等命令。
- 上传文件选择与拖拽上传、模拟分片进度、上传完成入库。
- 文件详情抽屉、多格式预览、收藏、重命名、回收站恢复与永久删除。
- 分享链接创建、有效期、提取码、访问权限、复制链接与撤销分享。
- 登录/注册界面、账户菜单、通知面板和移动端侧滑导航。
- 50 种以上文件扩展名的格式识别、配色和扩展名图标。

终端快捷键：Ctrl + Backquote（反引号键）。

## 后端接入

模拟数据与操作集中在 `src/composables/useFileManager.js`。接入后端时，可在这一层替换文件列表、上传、分享和回收站操作，页面组件无需感知具体 API。
